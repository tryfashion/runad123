# M2 本地实现与验收记录

日期：2026-09-12。范围仅当前商品采集和可编辑草稿；没有实现 DeepSeek、改写、正式 CSV 导出，也没有绕过风险检查的导出按钮。

## 实现

- MV3 当前站点可选授权，隔离世界读取 Shopify 商品接口，已授权站点检测标记；导航时清除标记，取消/超时清理请求。
- Ajax 优先，product.json 有界回退。只有回退自身带 currency 且与采集前后购物车 currency 一致才可接受，不将来源不明币种强行与价格混用。常见不带币种的 JSON 回退会拒绝。
- 原始响应先读取文本再无损解析，商品/规格 ID 字符串不失真；Ajax 百分单位与 JSON 十进制分开。JPY/KRW 按 Shopify Ajax 文档的百分单位处理，合成样本验证，不冒充真实店铺验证。
- 规范化来源、规格/图片引用、数量、选项、价格；达到 250 规格上限、订阅必选/组合或缺失引用明确失败。cart.js 只返回 currency 到采集结果。
- POST captures、GET/PATCH drafts 使用共享 Zod；服务端重算哈希、鉴权、访问开关、幂等与版本冲突。快照去重和单次采集事件在同一 MySQL 事务写入。
- sanitize-html 清理危险 HTML，htmlparser2 抽取可见文本；描述超长拒绝。插件使用禁脚本/禁资源的沙箱 iframe 预览。最终文本、国家、商品语言参与 textHash，CSV 设置参与 exportHash。
- 可编辑标题、描述、国家、商品语言与草稿设置；本地未保存编辑可恢复；身份切换清理编辑，旧身份在途响应不得重新写入草稿缓存。
- 当前继续沿用身份层全局配置行的短事务锁，保证锁顺序与跨进程幂等；高并发吞吐需实际压测后优化，不宣称无瓶颈。
