- 首屏不展示账号表单、匿名选项或弹窗；右上角账号链接进入插件内独立视图，返回不丢弃产品编辑。
- 首次打开不请求安装身份。采集当前商品可在本地预览；上传前展示用途说明，用户创建草稿时才通过现有接口建立匿名身份并上传。服务端强制登录、风险校验和导出要求不变。
- 新增简体中文、繁体中文、英文界面词典；语言切换不改变商品内容。
- 已构建开发插件并检查 360px 实际 Chromium 截图（artifacts/plugin-simple-home.png）；280/360/440px 编辑页面无横向溢出。
- 4 项独立 Chromium 用例通过：简约首屏与延迟匿名身份、三语言/持久化/教程导航、恢复草稿与风险状态、改写接受/拒绝与语言独立性。新用例验证第一次安装仅发生于保存、切换视图保留输入。

- 扩展、工具类型检查和格式/包边界检查通过。刷新 Chrome 中已加载的扩展并重新打开侧栏即可查看。

网站概览仅点击后挂载，读取当前页元信息（平台、店铺域名、主题、货币、市场国家和语言）；未识别显示未知，不读取整店商品/集合，也不请求截图或首页。读取失败可返回产品或重新授权读取。五秒超时、切换标签/页面使旧结果失效。新增 DOM 合成页面及模拟 Chrome 注入桥验证，截图 artifacts/website-overview.png；并回归简约首页与语言导航，共 3 项通过。


网站概览缓存：chrome.storage.local 按网站 origin 保存数据和成功读取时间。同网站不同路径共用，重开侧栏保持；固定 UTC+8 自然日判定，不受浏览器语言/电脑时区影响。当天命中不注入读取脚本、不申请权限，不提供绕过当天缓存的刷新按钮；次日进入更新，失败保留旧数据显示原缓存时间且可重试。2 项单元及 1 项浏览器用例通过（DOM/注入桥模拟），无服务端字段或数据库变更。


主题返利链接：后台配置及插件匹配显示完成，公开查询不要求注册且仅发送主题名，不发送当前店铺域名。网站缓存不持久保存返利地址；下次进入概览重新查询，因此后台停用后不等每日缓存过期。后台保存和插件启用/停用显示的两项浏览器测试通过（模拟 API），截图 theme-links-admin.png 与 website-overview.png 已查看。15 项相关单元测试通过；test-theme-links-mysql.ts 使用真实隔离 MySQL 验证保存、别名、停用、并发冲突，测试后恢复配置。主库仅添加空配置；真实推广链接和佣金归因仍待用户配置/验证。
